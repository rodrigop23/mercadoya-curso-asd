# Diagramas Archify históricos

Los HTML de `flujo-compra-v1/` y `flujo-compra-v2/` documentan demos anteriores. Su topología no representa el runtime S5 de `v3-services`: Orders, Inventory y Notifications ya corren fuera del proceso API. `flujo-pipeline/` muestra el pipeline local de imágenes, pero su UI admin también precede al MF iframe.

Para la arquitectura actual consulta [C4 contenedores S5](../c4-2-containers-v3.md), [compra S5](../seq-order-placed-fanout-v3.md) y [admin MF](../seq-admin-mf-catalog.md). Se conservan los HTML y JSON para comparar las etapas del curso.
