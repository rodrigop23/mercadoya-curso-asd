# Ruta de aprendizaje de IA (4 niveles)

Guía gratuita para estudiantes del curso **Arquitectura de Soluciones Digitales** (y cualquiera que quiera empezar desde cero).

Hay dos tramos claros:

1. **Nivel 0 (Base):** entender qué es la IA en general. Sin programar.
2. **Niveles 1–3:** usar la IA para aprender y trabajar con código (prompts, coding agents, skills).

No hace falta hacer _todos_ los cursos de cada nivel. En cada uno hay una ruta mínima recomendada.

---

## Cómo usar esta guía

| Si estás así…                                                            | Empieza en        |
| ------------------------------------------------------------------------ | ----------------- |
| No sabes qué es la IA, un LLM o el machine learning                      | **0. Base**       |
| Ya usas ChatGPT a ojo y quieres pedirle código / ayuda técnica           | **1. Básico**     |
| Ya prompts decentes y quieres Chat/Agent, revisar output, Copilot/Claude | **2. Intermedio** |
| Quieres dirigir agentes, skills y un flujo de ingeniería serio           | **3. Avanzado**   |

**Idioma:** varios recursos están en inglés. En Base hay opciones fuertes en español. En los demás, subtítulos de YouTube y Alison en español ayudan.

**Costo:** priorizamos contenido gratis. Algunos sitios ofrecen certificado de pago; el aprendizaje no lo requiere. En Coursera, al inscribirte elige **Auditar** / “Full Course, No Certificate” cuando exista.

## 0. Base — alfabetización en IA (sin programar)

**Para quién:** cero conocimiento de IA.

**Objetivo:** saber qué es la IA, qué puede y qué no puede hacer, vocabulario mínimo (aprendizaje automático / ML, IA generativa, LLM), y nociones de uso responsable. Todavía _no_ es “programar con IA”.

### Ruta corta (~2–3 horas)

Ideal si solo quieres lo esencial antes de pasar al Básico.

1. **[Introduction to Generative AI](https://www.cloudskillsboost.google/course_templates/536)** — Google Cloud Skills Boost · ~45 min · gratis  
   Espejo en Coursera (mismo contenido): [Introduction to Generative AI](https://www.coursera.org/learn/introduction-to-generative-ai)  
   Qué es la IA generativa y en qué se diferencia del machine learning “tradicional”.

2. **[Introduction to Large Language Models](https://www.cloudskillsboost.google/course_templates/539)** — Google Cloud Skills Boost · ~1 h · gratis  
   Espejo: [Introduction to Large Language Models](https://www.coursera.org/learn/introduction-to-large-language-models)  
   Qué es un LLM, para qué sirve y cómo se mejora con instrucciones (prompting a alto nivel).

3. **[Responsible AI: Applying AI Principles with Google Cloud](https://www.coursera.org/learn/responsible-ai-applying-ai-principles-with-google-cloud)** — Google Cloud / Coursera · ~2 h · auditable gratis  
   También en Skills Boost: [Responsible AI (course_templates/388)](https://www.cloudskillsboost.google/course_templates/388)  
   Riesgos, principios y uso responsable. Recomendable cerrar la ruta corta con este.

### Ruta más sólida (días o semanas, a tu ritmo)

Ideal si quieres una base conceptual seria.

1. **[Elementos de IA](https://www.elementsofai.com/es/)** — Universidad de Helsinki / MinnaLearn · gratis · **en español**  
   Estándar mundial para no expertos: qué es IA, resolución de problemas, ML, redes neuronales e implicaciones sociales. Sin matemáticas avanzadas ni programación. Completo: ~30–60 h; puedes avanzar por capítulos a tu ritmo.

2. **[IA Para Todos (Español)](https://www.coursera.org/learn/ai-for-everyone-es)** — DeepLearning.AI / Andrew Ng · Coursera  
   Visión de negocio y sociedad, sin código. Auditar el contenido suele ser gratis; el certificado suele ser de pago.

### Alternativa corta en español (ecosistema Google)

- **[Aprende IA desde cero (Grow with Google)](https://grow.google/intl/es/ai-opportunity/)** — intros sin experiencia previa.
- **[Google AI Essentials (ES)](https://grow.google/intl/es_es/ai-essentials/)** — fundamentos y prompting básico (landing Grow with Google).

### Qué dejar fuera de este nivel

- Cursos de Google AI Essentials en Coursera si te empujan a un trial de pago (usa Skills Boost o auditar).
- Cursos “gratis” con fuerte upsell (p. ej. algunos de Platzi).
- Ofertas con ventana de inscripción cerrada o solo regionales.

**Ritmo sugerido:** ruta corta en un día, o Elementos de IA a lo largo de 2–4 semanas. Luego pasa al Básico.

## 1. Básico — entender y pedir bien (IA para empezar a codear)

**Para quién:** ya tienes la idea general de IA (o saltaste el Base) y quieres usarla para aprender o escribir código sin miedo.

**Objetivo:** qué es un prompt, cómo pedir ayuda a la IA, primeros pasos con un coding agent / chat de código.

1. **[Cursor Learn](https://cursor.com/learn)** — oficial · gratis  
   Fundamentos y patrones para trabajar con modelos de IA al programar. Módulo directo: [How AI Models Work](https://cursor.com/learn/how-ai-models-work). Especialmente útil si en el curso usarán coding agents de escritorio.

2. **[AI Python for Beginners](https://www.deeplearning.ai/short-courses/ai-python-for-beginners/)** — DeepLearning.AI · gratis  
   Para quien casi no programa: usa un chatbot para escribir, explicar y depurar. Sin experiencia previa requerida.

3. **[Learn to Code with AI](https://scrimba.com/learn-to-code-with-ai-c02m)** — Scrimba · gratis  
   Práctica interactiva con ChatGPT para aprender a codear con IA.

4. **[Ingeniería de Prompts con IA Generativa](https://alison.com/es/curso/ingenieria-de-prompts-con-ia-generativa)** — Alison · gratis · **en español**  
   Tokens, contexto, prompts claros, few-shot y chain-of-thought. Buen puente si el inglés cuesta.  
   Versión EN: [Prompt Engineering With Generative AI](https://alison.com/course/prompt-engineering-with-generative-ai)

**Ruta mínima:** Cursor Learn + uno entre Scrimba, AI Python Beginners o Alison.

**Ritmo sugerido:** 1–2 semanas.

---

## 2. Intermedio — prompts fuertes + herramientas de coding

**Para quién:** ya pides cosas razonables a la IA y quieres un flujo más serio (Chat / Agent, revisar lo generado, varias herramientas).

**Objetivo:** mejores prompts, iterar, entender tokens/contexto/alucinaciones, y usar IDE/agents con criterio.

1. **[ChatGPT Prompt Engineering for Developers](https://www.deeplearning.ai/short-courses/chatgpt-prompt-engineering-for-developers/)** — DeepLearning.AI (Andrew Ng + OpenAI) · gratis  
   Principios de prompts, iteración y casos reales. Referencia estándar de la industria.

2. **[Anthropic Prompt Engineering Interactive Tutorial](https://github.com/anthropics/prompt-eng-interactive-tutorial)** — Anthropic · gratis  
   Nueve capítulos con ejercicios (estructura, fallos comunes, coding). Muy práctico.  
   Docs oficiales: [Prompt engineering overview](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview).

3. **[AI Tools for Developers](https://www.freecodecamp.org/news/ai-tools-for-developers/)** — freeCodeCamp · ~1.5 h · YouTube gratis  
   Tokens, contexto, alucinaciones, Copilot / Claude / Gemini, y cuándo _no_ usar IA. El artículo enlaza el video completo.

4. **[Cursor AI IDE Workflows](https://freeacademy.ai/courses/cursor-ai-ide-workflows)** — Free Academy · gratis  
   Chat, inline edit, Agent, contexto del repo y reglas.

**Ruta mínima:** Prompt Engineering (DeepLearning.AI) + freeCodeCamp _o_ workflows de Cursor.

**Ritmo sugerido:** 2–3 semanas.

---

## 3. Avanzado — agentes, skills y flujo de ingeniería

**Para quién:** ya usas agents day to day y quieres disciplina de ingeniería (no “vibe coding” a ciegas).

**Objetivo:** dirigir agentes, planificar, skills reutilizables, tickets chicos, contexto bien acotado.

1. **[Claude Code Full Course](https://www.freecodecamp.org/news/claude-code-full-course/)** — freeCodeCamp · ~1.5 h · gratis  
   Setup, goals, skills, MCP, GitHub. Mucho es transferible a otros coding agents.

2. **[Real World Prompting](https://github.com/anthropics/courses/tree/master/real_world_prompting)** — Anthropic · gratis  
   Después del tutorial interactivo: prompts complejos en escenarios reales.  
   Índice del repo: [anthropics/courses](https://github.com/anthropics/courses).

3. **[AI Coding For Real Engineers · Matt Pocock](https://frontiermodels.cc/video/full-workshop-ai-coding-for-real-engineers-matt-pocock-ai-hero-mattpocockuk/)** — workshop ~2 h · gratis  
   Zona “smart/dumb” del contexto, tickets pequeños, PRDs y disciplina al codear con IA.

4. **[Skills de Matt Pocock](https://github.com/mattpocock/skills)** + guía en [aihero.dev/skills](https://www.aihero.dev/skills) · gratis  
   Incluye patrones tipo `grill-me` / `grill-with-docs`. Instálalos y practícalos en un repo propio.

**Ruta mínima:** workshop de Matt Pocock + Claude Code (freeCodeCamp) + practicar 1–2 skills en un proyecto real.

**Ritmo sugerido:** 2–4 semanas.

## Orden sugerido para un alumno “perdido”

1. **Base:** ruta corta de Google (~2–3 h) _o_ al menos los primeros capítulos de Elementos de IA.
2. **Básico:** Cursor Learn + un curso práctico (Scrimba o Alison).
3. **Intermedio:** Prompt Engineering for Developers + freeCodeCamp AI Tools.
4. **Avanzado:** workshop de Matt Pocock + instalar y usar skills en un repo.

Si ya programas y solo te falta criterio con agents, puedes saltar el Base (o hacerlo muy ligero) y entrar por Básico → Intermedio.

---

## Notas finales

- Esta lista privilegia **calidad y gratuidad**, no exhaustividad.
- Los enlaces de Google Skills Boost a veces redirigen a `skills.google`; si uno falla en el navegador, usa el espejo de Coursera indicado junto a cada curso.
- En el curso ASD el foco práctico es **arquitectura** (no ser un curso de programación). Estos recursos son apoyo opcional para quien quiera mejorar su uso de IA al acompañar demos o proyectos.
